# Отчёт о редизайне LV24 Brain Desktop

Дата: 10 ноября 2026. Ветка: `design/ux-refresh`. Исходная версия: `6b2ca9d`.
Baseline Desktop `1.0.1`; целевой релиз этого рефреша — `1.1.0`. Версии движка и релизные настройки на этапе дизайна не менялись.
Изменения закоммичены локально. Push, PR, релиз и облачный CI не выполнялись.

## Изменения

- Семантическая тёмная тема: цвет, типографика, отступы, радиусы, слои и движение.
  Светлая тема намеренно не добавлена. Цвета иконок также читаются из CSS-токенов.
- Компактная оболочка, заметный маршрут, сброс прокрутки и фокус основного
  содержимого. На Dashboard одна основная поверхность движка, причина ошибки
  с восстановлением и доступ к последнему сбою без длинного списка над ним.
- Общие Input, Select, Field/FormRow, Table, EmptyState, Loading/Skeleton, Badge,
  Tabs, Tooltip и канал уведомлений; Button поддерживает ghost/danger/loading.
  Нативные disabled, диалоги и восстановление фокуса сохранены.
- Подключения: последний известный результат и дата, переход к журналу,
  поиск/фильтр при большом списке и сортировка. Неизвестная история обозначена
  явно. API не возвращает текст последней ошибки — выдуманных данных нет.
- Wizard разделён на компоненты; введены переходы к пройденным шагам, сохранение
  черновика и фокус первого ошибочного поля. Create payload и post-create retry
  сохранены; завершённый шаг не позволяет повторить создание.
- Detail: навигация по секциям без изменения hash-маршрута, состояние credentials
  loading/unknown/error/retry, последний известный запуск и отдельная danger zone.
- Настройки разделены на общие параметры и диагностику. Журнал различает потоки,
  поддерживает follow/pause объявлений, Copy и Save; новые строки не имитируются.
- Единая геометрия знака, wordmark, app icon и пяти tray-состояний; ICO/ICNS и
  все PNG/SVG воспроизводимо генерируются локальным PowerShell-скриптом.
- Новые переводы добавлены одновременно в en/ru/zh, старые ключи сохранены.

Полный перечень файлов: [changed-files.md](changed-files.md).
Аудит и обоснования: [../design-refresh.md](../design-refresh.md).

## Визуальная проверка

Все снимки сделаны в настоящем React UI через локальный **браузерный стенд с
вымышленными данными**, без настоящего движка, keychain или обращения к провайдерам.
Это не скриншоты запущенного нативного Tauri-приложения.

- 56 парных снимков: 7 страниц × before/after × 980×720/760×540 × en/ru.
- 7 снимков русского reflow при 380×270 CSS-пикселях — эквивалент рабочей области
  760×540 при масштабе 200%, без заявления о проверке настоящего browser zoom.
- 21 снимок empty/error/loading, диагностика настроек, завершённый wizard и журнал.
- [Индекс снимков](screenshots/README.md), [контраст](contrast.json),
  [контактный лист бренда](brand-contact.png), [пример сохранённого журнала](sample-log.txt).

DOM-метрики подтверждают отсутствие горизонтального переполнения. Имена снимков
обозначают заданный viewport, подтверждённый `innerWidth/innerHeight`. API захвата
иногда отдаёт меньший bitmap (например, 965×709 для viewport 980×720); изображения
не растягивались и не дополнялись рамкой для имитации другого размера.

Клавишей Tab пройдены видимые элементы всех семи страниц при 760×540, ru:
Dashboard 21, Connections 48, Wizard 16, Detail 28, Activity 27, Projects 11,
Settings 17 остановок. У всех проверенных интерактивных элементов видимый focus
и размер ≥24×24. Дополнительно проверены фокус первой ошибки формы, сохранение
черновика, mock create до Done, переходы вкладок стрелками, отмена Delete/Quit
с восстановлением фокуса и уведомление после смены маршрута. Журнал копируется
в clipboard и скачивается в файл; follow-off устанавливает `aria-live="off"`.
Подробности — [interaction-checks.json](screenshots/interaction-checks.json).

## Оставшиеся риски и ручная нативная приёмка

Нативный GUI новой сборки не запускался: уже работает установленное приложение
с тем же single-instance identifier. Оно и его движок не останавливались.
Debug build подтверждён; нативная визуальная приёмка остаётся открытой.

- [ ] После обычного завершения установленного приложения открыть debug exe;
  повторить семь экранов в en/ru при 980×720 и 760×540 и настоящем 200% zoom.
- [ ] Проверить clipboard/Save в WebView2, tray-глифы, pause/resume,
  close-to-tray, автозапуск, OAuth callback и updater без установки обновления.
- [ ] Проверить системные forced colors, prefers-contrast/reduced-motion
  и произношение screen reader; CSS-поддержка есть, системная эмуляция не проведена.
- [ ] Проверить иконки/трей нативно на macOS и Linux; ICNS декодируется локально,
  но платформенный GUI не проверен. Цветные tray-иконки сохранены на всех ОС;
  macOS template mode не включался.

Ограничения данных: 100 последних глобальных запусков и до 1000 полученных строк
журнала. Отсутствие запуска не означает отсутствие прошлой активности.
Текущий API не позволяет отдельно вывести текст last-error в строке подключения.
В development StrictMode у исходного RunsStore возможны дубли отложенных event
subscriptions; визуальный стенд монтирует App один раз, как production React.
Store/engine-поведение в этой задаче не переписывалось.

Локальные Vite-серверы стендов остановлены. Временный baseline-worktree
`C:\Users\Veeskela\.codex\tmp\lv24-brain-design-baseline` остался: автоматическая
проверка отклонила удаление его `node_modules` junction с причиной
`blocked by policy`. Удаление worktree вместе с junction не выполнялось;
основной `node_modules` и установленное приложение не затронуты.
